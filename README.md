# EduSpace - Platform Edukasi Digital

## Deskripsi

EduSpace adalah landing page platform edukasi digital yang membantu mahasiswa belajar secara lebih terarah, fleksibel, dan efektif.

Website ini dibuat untuk memenuhi tugas Pemrograman Web dengan menerapkan HTML5 semantik dan CSS modern.

## Tema

**Tema B - Katalog Produk Digital / Startup Edukasi**

## Fitur

- Value proposition platform edukasi digital
- Fitur unggulan
- Paket dan harga berlangganan
- Testimoni pengguna
- Call to Action (CTA)
- Navigasi antarbagian halaman
- Responsive design
